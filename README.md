# 1200g_algo_study

두근두근 알고리즘 스터디

## 소개
이 리포지토리는 주차별로 선정된 알고리즘 문제를 연습하고 공유하기 위한 스터디용 저장소입니다. 각 주차 폴더에 문제 설명을 Markdown으로 제공하며, 풀이 코드는 본인 이름 또는 닉네임의 하위 폴더에 주석과 함께 올려주세요.

## 목표
- 매주 문제를 풀고 풀이를 공유하여 알고리즘 실력 향상
- 다양한 풀이 방식 학습 및 코드 리뷰를 통한 피드백

## 구조 예시
```
README.md
1_week/
	문제.md
	your_solution.py
2_week/
	문제.md
	...
```

## 기여 규칙
- 각 주차 폴더에 문제와 풀이를 함께 관리하세요.
- 풀이 파일에는 간단한 설명(접근법, 시간복잡도 등)을 주석으로 남겨주세요.
- PR을 사용할 경우, 변경 내용과 간단한 설명을 함께 적어주세요.

## 코딩 스타일 권장
- 가독성 있는 변수명 사용
- 함수 단위로 분리하고, 입력/출력 예시는 주석으로 기재

## 연락 및 문의
궁금한 점이나 제안이 있으면 이슈로 남겨주세요.
